01 Set up your annotation project

Full annotation labels every row you see. Relabel 500 targets opens each post with its original 500 comments emptied and walks you through them. Both limits apply to each post separately. Depth decides how far down the conversation you see: 1 = the comments under the post, 2 = also their replies, 3 = deeper. Max comments is a hard count — after depth filtering each post keeps exactly its first N comments + replies, breadth-first and oldest first: at N = 5 the 5th is kept and the 6th is cut, even if nothing else follows. Each post has its own count; a big post never shrinks a small one, and every post stays in your list. The post row itself is free, and in 500-target projects each target and the replies around it always stay visible without consuming N.

Row structure

Tree paths are stored as JSON arrays inside the CSV cell, or as arrays in JSON exports. The path runs from the original post through each parent to the target.

Project filters

Blank = unlimited. Depth: 1 = only the post's direct comments, 2 = also their replies, 3 = one level deeper. Max comments is a hard count per post: after depth filtering, each post keeps exactly its first N comments + replies — breadth-first, oldest first — so at N = 5 the 5th is kept and the 6th is cut, even if nothing follows. Each post counts on its own; one big post never shrinks another, and the post row itself is free. In 500-target projects, targets and the replies around them always stay visible without consuming N. Existing labels are kept. Exports include saved labels or the full source, as selected.
